# 랜딩페이지 배포 안내

`docs/index.html` 한 파일이 전부다. 빌드 도구도, 서버도 필요 없다.

배포까지 **15분**, 전부 휴대폰으로 가능하다.

---

## 1. 폼 연결 (5분) — 이것부터 해야 신청이 저장된다

### Formspree (권장)

1. https://formspree.io 가입 (무료: 월 50건 제출)
2. **New Form** → 이름 아무거나 → 생성되면 `https://formspree.io/f/xxxxxxxx` 형태의 주소가 나온다
3. `docs/index.html` 을 열어 아래 한 줄을 찾는다 (Ctrl+F: `YOUR_FORM_ID`)

   ```html
   <form id="notifyForm" action="https://formspree.io/f/YOUR_FORM_ID" method="POST">
   ```

4. `YOUR_FORM_ID` 자리에 2번에서 받은 ID를 넣는다. 끝.

제출된 신청은 Formspree 대시보드에 쌓이고, 설정에서 이메일 알림도 켤 수 있다.
첫 제출은 확인 메일이 한 번 오니 직접 한 번 테스트해볼 것.

### 구글 폼으로 하려면

구글 폼은 `action` 주소와 필드 이름(`entry.xxxxx`)이 폼마다 달라서 손이 더 간다.
간단히 가려면 신청 버튼을 구글 폼 링크로 바꿔도 된다 — 다만 페이지를 떠나게 되므로 전환율은 떨어진다.

---

## 2. 배포 (5분)

### GitHub Pages

1. 저장소 → **Settings** → 좌측 **Pages**
2. Source: **Deploy from a branch**
3. Branch: 이 브랜치 선택 + 폴더는 **`/docs`** 선택 → Save
4. 1~2분 뒤 `https://<계정명>.github.io/<저장소명>/` 에서 열린다

> 지금 이 파일들은 `claude/ai-advisor-system-review-et574u` 브랜치에 있다.
> Pages 는 아무 브랜치나 지정할 수 있으니 그대로 써도 되고, `main` 에 머지한 뒤 main 을 지정해도 된다.

### Vercel (커스텀 도메인 붙이기 쉬움)

1. https://vercel.com 에서 깃허브 계정으로 로그인 → **Add New Project** → 이 저장소 선택
2. Framework Preset: **Other**, Root Directory: **`docs`**
3. Deploy → 끝

---

## 3. 배포 전 마지막 확인

- [ ] `YOUR_FORM_ID` 를 실제 폼 ID로 바꿨다
- [ ] 푸터의 `문의: (연락처)` 를 실제 연락처(카톡 ID나 이메일)로 바꿨다
- [ ] 휴대폰으로 열어서 위에서 아래까지 한 번 읽었다
- [ ] 직접 신청을 넣어보고, 저장되는 걸 확인했다

## 설계 근거 (나중에 고칠 때 참고)

명세서에 없던 판단만 적어둔다.

- **웹폰트를 쓰지 않았다.** 기기 기본 한글 폰트가 모바일에서 가장 빠르고 잘 읽힌다.
  서체 역할 분리는 굵기·크기·자간·행간으로 했다.
- **색은 3개.** 배경 `#E8EAE6` / 본문 `#232722` / 강조 `#45604F`.
  금지된 조합(크림+세리프+테라코타, 검정+형광)을 피하면서 조용한 톤을 유지했다.
- **시그니처는 하나뿐이다.** 히어로 아래 점 20개가 하나씩 켜진다 = 20일치 질문이 도착하는 감각.
  질문 내용은 보여주지 않는다 — FAQ에서 "미리 알려드리지 않는다"고 했기 때문이다.
- **애니메이션은 스크롤 진입 페이드까지만.** `prefers-reduced-motion` 을 켠 사람에겐 전부 즉시 표시된다.
- **폼은 JS 없이도 작동한다.** JS가 있으면 페이지 이동 없이 완료 메시지로 바뀌고,
  없으면 일반 POST로 제출된다. 스팸 봇용 함정 필드(`_gotcha`)도 넣어뒀다.
- **세 번째 칸(요즘 답답한 것)은 시각적으로 줄이지 않았다.** 명세서대로 다른 필드와 같은 크기다.

## 만들지 않은 것

명세서 6장 그대로: 결제, 로그인, 관리자, DB, 다크모드, 다국어, 노션 연동, 자동 발송, AI 분석.
필요해 보여도 이번 페이지의 일은 연락처를 받는 것 하나다.
